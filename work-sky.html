Android / iOS 双端

天空社区 · 资讯社区 App

信息流 + 频道 + 搜索 + 分享海报 · 双端同一套代码

项目介绍

一个面向资讯与话题讨论的社区型 App：首页信息流按「全部 / 市场 / 科技 / 区块链 / 商业 / 宏观」分频道， 支持下拉刷新、上拉加载与按频道切换；文章详情、搜索、个人中心、深色模式一并打通。 内容可一键生成分享海报，用于站外拉新。

Android 与 iOS 共用一套业务代码，两端行为一致；登录走手机号 + 短信验证码， 未登录状态下可浏览、进入个人中心时再引导登录。

  • uni-app
  • Vue 3
  • Android / iOS
  • 短信验证码登录
  • Canvas 分享海报
  • 深色模式

端到端操作流程

手机号验证码登录 → 频道信息流 → 文章详情 → 分享海报生成 → 个人中心与深色模式切换。

  • 50 秒
  • 竖屏
  • 无声

录屏已静音、压缩为 H.264，手机与桌面浏览器均可直接播放。

功能要点

  • 信息流与频道 —— 顶部分类横滑切换，支持下拉刷新与分页加载；不同频道复用同一套列表组件，减少重复代码。
  • 分享海报 —— 用 Canvas 动态绘制带二维码的海报，不依赖截图或第三方截图库，生成结果可直接保存到相册。
  • 登录态 —— 手机号 + 短信验证码，含 60 秒倒计时与重复发送限制；未登录可浏览，触发个人中心时才引导登录，降低首屏门槛。
  • 双端一致 —— Android 与 iOS 由同一套代码产出，交互与样式保持一致，维护成本只有一份。
  • 深色模式 —— 个人中心可手动切换深浅色，配色跟随主题变量整体切换。
