uni-app X 原生渲染 · Java 服务端 · Vue3 管理后台 · H5 分享落地页

项目介绍

一款财经资讯 App，内容以文章为主体：首页聚合头条、栏目和最新列表，可按栏目切换， 支持全站搜索；文章详情渲染富文本。读过和想留的文章可以在本机留下浏览记录与收藏， 分享时生成带二维码的海报存进相册，或者把文章链接发到微信，打开是带下载引导的 H5 页面。 深色和浅色两套主题可手动切换并记住选择。

交付范围是四端：Android 与 iOS 双端 App、Java 服务端、Vue3 管理后台、H5 分享落地页。 后台负责内容发布：文章和短资讯两种形态，富文本编辑、配图、摘要、栏目归属，立即 / 定时 / 存草稿三种发布方式；另有栏目管理（可拖拽排序、指定头条）和数据统计（阅读量趋势、栏目分布、Top 10、Excel 导出）。 登录只做手机号加短信验证码，未登录可以正常浏览全部内容。

管理后台

左右滑动查看。后台是独立的 Vue3 + Element Plus 单页应用，挂在 /admin/ 子路径下。统计支持近 7 / 30 / 90 天与自定义区间，栏目顺序可拖拽调整，改完 App 端下次进入即生效。

技术要点

  • 蒸汽模式（Vapor）原生渲染。视图层从虚拟 DOM + diff 改成字节码，逻辑层不用 UTS 编译成 Kotlin，改由引擎驱动。切换前逐条核对了官方硬约束：只能组合式 API、CSS 只支持简单 class 选择器、scroll-view 的 scroll-y 已废弃、<text> 只能有一个文本节点。落地成本是 2 个文件改动加 4 个编译错误，约半天。
  • 列表接口不带正文。首屏列表返回的正文长度为 0 字符，配图字段保留。列表响应 gzip 后 2.9 KB，20 条数据，弱网下也不会拖慢首屏。
  • 富文本的渲染边界。编辑器只保留 App 能渲染的格式：标题、加粗、斜体、下划线、有序和无序列表、引用、分割线、图片、链接、对齐、颜色。表格、多列、视频这类 App 渲染不了的，在粘贴时就被拦掉，保证「编辑所见即 App 所见」。
  • 定时发布与草稿。发布方式分立即、定时、存草稿三种。到点由服务端触发发布，不依赖打开后台，App 端只显示已发布状态的文章。
  • 本机存储的边界。浏览记录和收藏都只存在设备本地，不做云端同步；后台能看到的是阅读量这类匿名统计，不涉及用户行为画像。
  • 分享链路。海报由服务端提供数据、客户端合成，含标题、摘要、配图和二维码；复制链接走 H5 落地页，页面本身 1.1 KB、零外部资源，底部放下载引导，微信内打开即可阅读。
  • 阅读量的两种口径。页面上「总阅读量」卡片含已删除文章，Excel 导出则按 deleted = 0 过滤、不含回收站——内容盘点不该算已删的稿子，但运营拿导出行数去对总数会对不上，所以两处都写明了口径。阅读量给四列：累计取文章自身的计数，近 7 / 30 / 90 天从阅读日志算，三个区间固定并存，不跟页面选的区间联动。
  • 登录与权限。App 端手机号加短信验证码，登录态本地保持；未登录可浏览全部内容。后台单独一套账号体系，密码用 BCrypt 哈希，不存明文，连续 5 次错误锁定 10 分钟，登录有效期 7 天。
