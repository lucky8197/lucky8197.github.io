运行中 · 阿里云 ECS

盯价 PriceWatch · 价格库存监控系统

通用价格与库存监控 · Python + Flask + SQLite 全栈实现

项目介绍

解决的是一个很实际的问题：海外奥莱站的折扣和补货窗口很短，靠人肉刷新根本盯不住。 系统全量监控目标站点 223 个商品，15 分钟一轮定时采集（5-30 分钟可在面板调整）， 发现降价、尺码补货、新商品上架、下架后重新上架四类变动时，实时推送到飞书群。

配套 Web 面板可直接查看商品列表、价格历史曲线、尺码库存矩阵与事件时间线，手机 / 平板 / 电脑均可访问； 目前以 systemd 服务方式部署在阿里云 ECS 上持续运行。

  • Python 3.11
  • Flask
  • APScheduler
  • SQLite
  • 飞书开放平台
  • systemd

技术要点

  • 采集与解析 —— 基于 sitemap.xml 全量发现商品，仅抓取公开页面；随机延时 + 限流退避 + 失败快速重试，跨境链路不稳定的情况下也能长期跑稳。
  • 事件检测 —— 降价（阈值可调，默认 ≥5%）、尺码补货（缺货 → 有货）、新商品、重新上架四类事件；同一变动 24 小时内只通知一次，多变动合并为一条摘要，防骚扰。
  • 可靠性设计 —— 站点改版 / 解析异常自动告警；sitemap 商品数量骤降守卫（连续 3 轮才认定真实下架）；进程异常退出由 systemd 自动拉起。
  • 飞书通知 —— 群机器人 + 自建应用双通道，通知带商品图与官网直达链接；图片上传失败自动降级为纯文字，不影响事件触达。
  • Web 面板 —— 商品列表、价格历史曲线、尺码库存矩阵（颜色 × 尺码）、事件时间线、手动「立即检查」；带访问口令，轮询间隔与降价阈值可在面板直接调整，无需重启。
  • 部署运维 —— systemd 一键安装脚本（装依赖、建专用账号、注册服务、健康检查 7 步自动完成），数据 30 天滚动清理，升级保留数据库向后兼容。
