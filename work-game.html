暗能共鸣 · 微信小游戏

2D 竖屏生存射击 · TypeScript + Canvas 2D · 自研混合 ECS 引擎 · 运行时零第三方依赖

项目介绍

《暗能共鸣》是一款 2D 竖屏生存射击小游戏（类《吸血鬼幸存者》玩法）：玩家在不断涌来的怪物潮中生存， 一边拾取经验升级技能组合，一边挑战多阶段进化的 Boss。适配刘海屏 / 挖孔屏等主流机型， 运行时零第三方依赖——包括引擎在内全部自研。

  • TypeScript
  • Canvas 2D
  • 自研 ECS 架构
  • 对象池 / 空间哈希
  • 微信流量主

技术要点

  • 自研混合 ECS + OOP 引擎 —— 实体复用（freelist）、11 种组件 SoA 存储、9 个系统的有序调度、事件总线解耦，兼顾性能与可维护性。
  • 技能系统 —— 10 个主动 / 被动技能，各 8 级成长（关键等级触发质变效果），5 组技能 Combo 联动。
  • Boss 战 —— 3 位 Boss 按血量多阶段进化（技能状态机），实现重锤预警、冲撞、追踪符咒、旋转激光、落雷等机制原语。
  • 性能工程 —— 空间哈希 + 对象池支撑同屏大量实体；依据云测报告定位并修复 iOS 高 CPU 与内存峰值，对绘制热路径做零分配改造（内联向量、快照迭代、状态切换裁剪），粒子预算随 FPS 自适应。
  • 内容迭代（5 期） —— 局内商店与 6 件遗物、随机事件、每日挑战（日期种子确定性生成）、4 角色差异化、图鉴 + 17 项成就。
  • 商业化与社区 —— 接入微信流量主，激励视频复用贯穿「广告复活 / 结算金币 ×2 / 开局增益」三处玩法位，插屏广告单实例复用 + 局间隔频控（对局生态节奏优先）；开通游戏圈并内置入口，日常运营玩家社区。
