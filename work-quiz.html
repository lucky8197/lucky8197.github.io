成品工程 · H5 + 小程序双端

答题测算 · 知识闯关活动

答题 → 计分 → 称号 → 海报 → 抽奖 · Vue 3 / Fastify / Taro 三端实现

项目介绍

面向单位 / 政府宣传活动的答题测算模板：参与者依次作答 10 道题，提交后由服务端统一判分， 按各维度得分生成专属称号与宣言（如「全谷物健康专家」），可一键生成个人分享海报； 达到分数线实时解锁转盘抽奖，抽中实物填写收货信息。

同一套后端配两个前端：H5 端匿名即玩（适合公众号文章嵌入），小程序端走微信云托管免授权； 内置管理后台负责参与统计、题库维护与中奖名单导出。换一套题库与称号文案， 就能从「粮食日健康测算」变成「消防知识闯关赛」，适合批量交付同类宣传活动。

  • Vue 3
  • Vite
  • TypeScript
  • Fastify
  • Prisma + MySQL
  • Taro 4 + React
  • Canvas 海报

技术要点

  • 服务端判分与测算 —— 作答明细提交后由服务端统一判分，按维度得分映射分数段生成称号与宣言，前端改不了结果；支持多活动共用一套后端（URL 指定活动场次）。
  • 分享海报 —— 服务端合成个人测算海报（得分 / 称号 / 宣言 / 小程序码），长按即可保存转发，自带活动传播路径。
  • 抽奖闭环 —— 达到分数线实时开奖、每人限抽一次；后端先定奖、库存原子扣减防超发、幂等占位防重放；概率公示接口只下发总数与理论概率。
  • 双端分治 —— 业务功能不依赖小程序独有能力，唯一分岔是微信身份：小程序走云托管注入 openid（零前置），H5 用匿名 id 免授权即玩。
  • 管理后台 —— 参与统计、题库管理（含 CSV 导入导出批量建题）、分数段配置、中奖名单导出，口令访问。
