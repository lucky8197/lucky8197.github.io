成品工程 · H5 + 小程序双端

找不同闯关 · H5 活动游戏

找不同 + 答题绑定 + 大转盘 · Vue 3 / Fastify / Taro 三端实现

项目介绍

一套可直接部署上线的营销活动游戏：玩家在 3 个关卡中分别找出 5 / 7 / 10 处不同； 卡关时点「获取提示」弹答题，答对解锁 1 处位置提示；找齐后弹通关答题，答对进下一关； 三关全部通过解锁大转盘，抽中实物填写收货信息。从玩法、判定、抽奖到概率公示是一条完整闭环。

前端 H5（Vue 3）与小程序（Taro + React）共用同一套后端接口；后端 Fastify + Prisma + MySQL， Docker 两阶段构建，可部署到微信云托管或任意服务器。

  • Vue 3
  • Vite
  • Pinia
  • TypeScript
  • Fastify
  • Prisma + MySQL
  • Taro + React

技术要点

  • 服务端命中判定 —— 前端只上报归一化坐标（0-1），服务端换算像素坐标后与热点做距离判定，结果改不了；热点用百分比定位，换设备换分辨率不用重算。
  • 玩法闭环 —— 提示题 / 通关题双答题节点，提示数量以本关差异数封顶；每关 3 张备选图服务端随机下发（多图轮换），进度由服务端管理。
  • 抽奖三件套 —— 后端先定奖、前端转盘只负责转到指定扇区；库存原子扣减（UPDATE ... WHERE stock > 0）防超发；幂等占位防连点重放。
  • 合规动作 —— 概率公示接口只下发奖品总数与理论概率，不下发剩余库存；规则页覆盖参与条件、兑奖方式、隐私政策等有奖销售法定披露项。
  • 身份与部署 —— H5 匿名身份（localStorage 随机 id）免授权登录即可玩；小程序端由微信云托管注入 openid；H5 产物与后端同源挂载，免跨域配置。
