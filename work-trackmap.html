轨迹记录生成器 · 行程海报 App

输入起终点与时间，生成一张导航 App 风格的行程海报

项目介绍

填起点、终点和到达时间，出来一张和主流导航 App 差不多的行程海报，带地图底图、起终点标记、里程和耗时。 历史记录按月归档，可以一键导出成一张长图。

完全离线：记录存在本机 SQLite，图片直接进相册，不经过任何云服务器。 同一份代码同时产出 Android APK 和 H5 预览页。

  • uni-app
  • Vue 3 + Vite
  • Canvas 离屏绘制
  • SQLite
  • 百度地图
  • 离线打包 APK

完整使用流程

选择起点与终点 → 地图选点 → 设定到达时间 → 生成行程海报 → 存入足迹 → 按月归档与长图导出。

  • 104 秒
  • 竖屏
  • 无声

录屏已静音并转成 H.264，手机和桌面浏览器都能直接播。

技术要点

  • Canvas 离屏绘制。海报和长图都是代码画出来的，不是截屏，也不引 html2canvas；底图、路线、起终点图标和文字都在同一套绘制流程里合成。
  • 绕过 App 逻辑层的绘制限制。App 的逻辑层是独立 V8 线程，既没有 document 也没有离屏 canvas，直接画会报错。改成逻辑层取底图、视图层用 renderjs 绘制。判断走哪条路也从「是不是 App 运行时」换成探测有没有 document，这样不受运行时初始化时机影响。
  • 本地存储。记录存 SQLite，图片进相册，没有服务端。断网也能出图，内置了两条离线样例数据。
  • 视觉还原。深色模式 UI 配浅色导航风格海报，按参考图对过。到达时间改成按路线耗时自动推算，免得和里程对不上。
  • 打包与验证。本机离线打包约 40~75 秒出 APK。签名、包名、版本号、权限、SQLite 模块有脚本自动校验；真机上把生成海报、存入足迹、足迹页加载逐项走通。
